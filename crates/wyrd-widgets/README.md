# wyrd-widgets

Declarative `WidgetTree`, Flexbox/Grid/Absolute layout engine, style inheritance, reactive data binding (`bind`, `repeat_over`), and `render_bridge` scene graph construction for the Wyrd ecosystem.

Part of the [`wyrd-engine`](https://github.com/xximxxhatedxx/wyrd-engine) workspace.
