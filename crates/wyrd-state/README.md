# wyrd-state

Cross-process atomic state persistence (`theme.toml` and `wallpaper.toml`) for the Wyrd desktop ecosystem.

Has zero internal `wyrd-*` dependencies so lightweight daemons (`wyrd-wallpaper`, `wyrd-greet`, `wyrd-shell`) can synchronize Material You palettes and active wallpaper state without pulling in rendering or Wayland dependencies.

Part of the [`wyrd-engine`](https://github.com/xximxxhatedxx/wyrd-engine) workspace.
